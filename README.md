# ASP.NET Core Web API

A backend API project built with ASP.NET Core and C# for learning and practicing backend development.

## Current Features
- User Registration and Login
- JWT Authentication
- Employee Management API
- Entity Framework Core
- SQL Server / LocalDB Integration

## Project Status

**Work in Progress 🚧**

This project is currently under development and is not yet complete. Some features may have errors or may not work as expected. API endpoints are still being tested, and remaining issues will be fixed as development continues.

## Learning Goals
- Understand REST API development
- Practice authentication and authorization
- Work with databases using Entity Framework Core
- Learn API testing with Postman

## Technologies
- C#
- ASP.NET Core Web API
- .NET 10
- Entity Framework Core
- SQL Server
- Postman

## Disclaimer

This is a learning project and is not intended for production use yet.
